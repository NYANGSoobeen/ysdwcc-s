# 📌 채팅방 위 고정 옮기기 (지원팀 앱 등 다른 앱용)

카톡 채팅방 공지처럼, 메시지를 고정하면 그 방 맨 위에 띠로 계속 보여요. 방마다 하나.

| 파일 | 내용 |
|---|---|
| `chatpin.js` | 고정·내리기·띠 그리기·그 말로 이동·접기 — 프론트 앱 `js/chatpin.js` 그대로 |
| `chatpin.css` | 띠 모양 · 접힌 버튼 · 이동했을 때 반짝임 |

## 다른 앱의 Claude Code에 이렇게 부탁하세요 (3개 파일 첨부)
> 첨부한 `chatpin.js`·`chatpin.css`·`README.md` 는 다른 앱(양산동원로얄CC 프론트)의 **채팅방 위 고정(📌)** 기능이야. 우리 앱 채팅에도 **똑같이** 넣어 줘.
> - `chatpin.js`·`chatpin.css` 를 그대로 쓰고, README 의 "연결할 곳"을 우리 앱 채팅 코드에 맞게 연결해 줘
> - 데이터 모양(`channels/{방}.pin`)은 바꾸지 말고 그대로
> - 프론트 방(게스트로 들어간 방)에서도 고정된 띠가 보이게 해 줘 (README 아래 "프론트 방에서" 참고, 거기선 보기·이동만)
> - 휴대폰(아이폰·갤럭시)과 PC에서 확인하는 방법도 알려 줘

## 동작
- 메시지 길게 누르기(PC 우클릭)·⋯ 메뉴 → **📌 채팅방 위에 고정** (이미 고정된 말이면 **📌 고정 내리기**)
- 다른 말이 고정돼 있으면 "바꿀까요?" 물어봄 (방마다 하나)
- 띠: 📌 + 내용 2줄 + "쓴 사람 · 고정: 고정한 사람" · 오른쪽 **⌃ 접기**, **⋯**(그 말로 이동 · 복사 · 접기 · 고정 내리기)
- 띠를 누르면 그 말로 이동하고 1.8초 반짝 · 화면에 없는 옛날 말이면 글 전체를 창으로
- 접기는 이 기기에서만 (localStorage `ydr_pinfold_방_고정시각`, 새로 고정하면 다시 펼쳐짐) → 오른쪽 위 작은 "📌 고정된 말" 버튼
- 고정된 말을 **수정**하면 띠 내용도, **삭제**하면 고정도 내림

## 데이터 모양
`channels/{방}.pin = { mid: 메시지 id, text: 요약(200자), authorId: 쓴 사람, by: 고정한 사람, at: 고정 시각(ms), msgAt: 메시지 시각 }` (없으면 고정 없음)
- 채팅방 문서에 같이 저장 → 방 목록을 실시간으로 받고 있으면 읽기가 더 늘지 않음
- 직원이 채팅방 문서를 고칠 수 있는 보안 규칙이면 그대로 됨 (아니면 `pin` 만 바꾸는 것 허용 추가)

## 연결할 곳 (`chatpin.js` 가 기대하는 것)
1. **전역 값·함수** (이름이 다르면 `chatpin.js` 위쪽에서 맞춰 주기)
   - `channels`(방 목록 배열 `[{id, …방 문서}]`, 실시간), `currentChannel`, `currentView`(채팅이면 `'chat'`), `db`·`firebase`(compat), `myId`, `$`(= id로 찾기)
   - `toast`·`fail`·`uiConfirm`·`uiForm(제목, [], {message, okLabel})`·`displayNameFor(id)`·`copyText(글)`·`fmtTime(ms)`
   - `menuButton('⋯', ()=>메뉴들)` (누르면 메뉴 뜨는 버튼) · `msgImageIds(m)`(사진 id들, 없으면 빼도 됨)
   - **`chatFindPin(메시지id)`**: 그 말을 화면 가운데로 몇 초 붙잡아 두는 함수 (프론트는 검색 이동에 쓰는 것) — 없으면 아래처럼 만들기
     ```js
     function chatFindPin(id){ const box=$('messages'), r=box.querySelector('.msgRow[data-mid="'+id+'"]'); if(r) r.scrollIntoView({block:'center'}); }
     ```
2. **화면**: 채팅 메시지 목록(`#messages`) 바로 위에 `<div id="chatPinBar" style="display:none"></div>` · 메시지 줄마다 `class="msgRow" data-mid="메시지id"` (안에 `.msg` 말풍선)
   - 다른 화면으로 갈 때 `#chatPinBar` 숨기기
3. **부르는 곳**
   - 방을 열 때와 방 목록이 바뀔 때마다: `chatPinRender()`
   - 메시지 메뉴에: `...chatPinMenuItems(m)`
   - 메시지 수정 저장 뒤: `chatPinOnEdit(m, 새글)` · 삭제 뒤: `chatPinOnDelete(m)`
4. **📱 휴대폰 키보드**: 키보드가 열리고 닫힐 때 채팅을 맨 아래로 내리는 코드가 있으면, 막 이동한 참(몇 초)에는 내리지 않게 막기 (안 그러면 띠를 눌러 이동해도 바로 맨 아래로 튕김)

## 프론트 방에서 (게스트로 들어간 방)
- 프론트 방 문서 `channels/{ch}` 를 이미 읽고 있으니 `pin` 이 있으면 같은 띠로 보여 주고, 누르면 `pin.mid` 메시지로 이동
- **고정·내리기는 프론트 직원만** (게스트는 방 문서를 못 고침) → 프론트 방에선 메뉴에 📌 항목 빼고, 띠의 ⋯ 에서도 "고정 내리기" 빼기
- 접기(이 기기에서만)는 게스트도 그대로 써도 됨
