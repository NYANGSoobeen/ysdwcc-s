# 🐾 우리 펫 같이 키우기 (지원팀 앱용)

프론트 앱의 "우리 펫"을 지원팀 앱에도 넣어서 **같이 키워요**. 지원팀 직원도 한 사람당 한 마리씩 데려오고, 프론트 펫과 지원팀 펫이 **프론트 방(게스트로 들어간 방) 채팅 화면** 아래를 같이 돌아다녀요. 프론트 앱에서는 지원팀 펫도 보여요.

| 파일 | 내용 |
|---|---|
| `pets.js` | 프론트 앱 `js/pets.js` 를 그대로 옮긴 파일이에요. 창 클래스 이름만 `petBgWrap`·`petSheet` 로 바꿨어요. 픽셀 캐릭터 그림, 돌아다니기, 들기·흔들기·던지기, 고양이 점프, 물기·핥기, 목욕, 낚싯대, 공 던지기, 어질리티가 다 들어 있어요. **고치지 말고 그대로 써 주세요** (프론트가 바뀌면 새로 받기). |
| `pets.css` | 펫·창·놀이 모양이에요. |

## 다른 앱의 Claude Code에 이렇게 부탁하세요 (3개 파일 첨부)
> 첨부한 `pets.js`·`pets.css`·`README.md` 는 다른 앱(양산동원로얄CC 프론트)의 **🐾 우리 펫** 기능이야. 우리 앱에도 넣어서 프론트와 **같이 키우게** 해 줘.
> - `pets.js`·`pets.css` 는 고치지 말고 그대로 넣어 줘. 이 README 의 "연결할 곳"대로 `window.PET_HOST` 를 만들어서 연결해 줘.
> - 데이터는 프론트 Firebase(이미 게스트로 접속하는 두 번째 앱 `ydr`)의 `pets`·`petFx` 컬렉션을 써. 모양은 바꾸지 마.
> - 펫은 **프론트 방 채팅 화면**에서만 돌아다니게 해 줘. "🐾 우리 펫" 버튼도 그 화면에 만들어 줘.
> - 휴대폰(아이폰·갤럭시)과 PC에서 확인하는 방법도 알려 줘.

## 할 수 있는 것
- 처음에 고양이 7종·강아지 9종 중 한 마리를 고르고 이름을 지어요. 펫은 `pets/{내 게스트 uid(g_…)}` 에 저장돼요.
- 펫을 끌면 들어 올려요. 들고 흔들면 방향 따라 대롱대롱 흔들리고, 놓으면 던져져요. 누르면 반가워해요.
- 🐱 고양이는 말풍선 위로 폴짝 올라가요. 🦷 말풍선 끝을 물면 잠깐 찌그러지고, 🐶 강아지는 핥아서 침 자국을 남겨요. 이 자국은 프론트·지원팀 모두에게 보여요. 글 내용은 안 바뀌어요.
- 목욕한 지 3일이면 꼬질, 7일이면 엄청 꼬질해져요 → 🛁 목욕
- 🎣 낚싯대(고양이), 🎾 공 던지기·🏃 어질리티(강아지)
- 누구 펫이든 같이 놀고 목욕시킬 수 있어요. 이름·종류 바꾸기와 지우기는 주인만 할 수 있어요.
- 🎭 품종마다 성격이 있어요 (`PET_TRAIT`). 짖기·하악질, 자꾸 누르거나 마구 흔들면 물기, 겁쟁이는 도망, 강아지가 고양이를 쫓으면 고양이가 하악질하거나 말풍선 위로 도망쳐요. 이건 각자 화면에서만 움직이는 거라 저장은 안 해요.
- 🌧️ 비 젖기는 프론트 날씨 탭에만 있어요. 지원팀 앱에서는 안 일어나요.

## 연결할 곳: `window.PET_HOST` (pets.js 를 불러오기 전에 만들기)
```js
import { getFirestore, collection, doc, onSnapshot, setDoc, updateDoc } from 'firebase/firestore';
import { getAuth } from 'firebase/auth';
const ydb = getFirestore(ydr);            // 이미 만들어 둔 두 번째 앱 'ydr' (GUEST_LINK.md 1번)
window.PET_HOST = {
  // pets.js 는 옛 방식(compat) 모양으로 불러요 → 이 작은 다리만 만들면 돼요
  db: {
    collection: name => ({ onSnapshot: (ok, bad) => onSnapshot(collection(ydb, name), ok, bad) }),
    doc: path => ({ set: d => setDoc(doc(ydb, path), d), update: d => updateDoc(doc(ydb, path), d) }),
  },
  me: () => getAuth(ydr).currentUser?.uid,          // 프론트에 게스트로 로그인한 uid (g_…)
  myName: () => '내 이름',                           // 목욕시킨 사람 이름으로 나와요
  ownerName: id => id.startsWith('g_') ? '지원팀 직원 이름' : '프론트 직원 이름',   // 프론트 직원 이름은 accounts/{id}.name (게스트도 읽기 가능)
  hidden: () => !프론트방채팅화면이열려있음 || 키보드가열려있음,   // true 면 펫을 숨겨요
  area: () => ({ l, r, top, floor }),   // 펫이 다닐 칸 (화면 기준 px): 채팅 영역 왼쪽·오른쪽, 위(머리줄 아래), 바닥(입력창 바로 위)
  platSel: '.채팅말풍선 선택자',          // 고양이가 올라갈 말풍선들
  platKey: el => 'm:' + 메시지id,       // 그 말풍선의 프론트 메시지 id (channels/{방}/messages/{id})
  fxSel: t => t.startsWith('m:') ? `.채팅말풍선[data-…="${CSS.escape(t.slice(2))}"]` : null,   // 'm:메시지id' → 그 말풍선 CSS 선택자
  toast: msg => 그앱의알림(msg),
};
```
- 로그인(게스트 토큰) 뒤에 `petsInit()` 을 한 번 불러 주세요.
- "🐾 우리 펫" 버튼은 `openPets()` 를 부르면 돼요.
- `pets.css` 의 색 변수(`--bg --card --text --sub --line --accent --accent2 --bubble`)가 그 앱에 없으면 그 앱 색으로 정해 주세요.
- 펫 층(`#petLayer`)은 z-index 12, 창(`.petBgWrap`)은 50이에요. 그 앱 메뉴·창과 겹치면 숫자를 맞춰 주세요.

## 데이터 모양 (바꾸지 말기)
- `pets/{id}` = `{owner:id, sp:종류키, name:이름(12자), createdAt, bathAt, dirt:더해진 꼬질 시간, wetAt, agi:어질리티 최고점, bathBy:목욕시킨 사람}`
  - 지원팀 직원의 id 는 **게스트 uid(g_…)** 예요. 프론트 직원은 로그인 아이디예요.
- `petFx/{id}` = `{list:[{k:'bite'|'lick', t:'m:메시지id', at, ox, low}] (최근 8개), at}`. 주인 기기만 써요.
- 보안 규칙은 프론트 쪽에 이미 들어 있어요. 게스트는 모두 읽기, 자기 펫 만들기·고치기, 아무 펫이나 목욕·놀이 결과만 바꾸기, 자기 petFx 쓰기가 돼요.

## 확인 순서
1. 지원팀 앱 프론트 방 → 🐾 우리 펫 → 한 마리 데려오기 → 채팅 화면 아래에 나오는지
2. 프론트 앱에서도 그 펫이 보이는지 (이름 옆에 지원팀 직원 이름)
3. 펫 끌어서 흔들기·던지기, 목욕, 낚싯대·공·어질리티
4. 프론트 펫이 말풍선을 물면 지원팀 화면에서도 그 말풍선이 잠깐 찌그러지는지
